1. VISION AND PITCH
----------------------------------------------------------------------
"We removed every manual step in the billing month, from the quote to the cash in the bank."
Brightloop Software sells recurring software subscriptions and services. BillPilot replaces spreadsheet-driven billing, manual invoice matching, and blind revenue leakage with a single automated subscription engine.

2. PERSONAS
----------------------------------------------------------------------
- Admin: Full control over staff creation, product catalog, plans, tax rules, discounts, and system configuration.
- Staff: Day-to-day operations: creating quotation templates, managing subscriptions, issuing invoices, recording payments, and customer support.
- Finance Lead: High-level financial visibility: MRR/ARR movement, revenue leakage detector, bank reconciliation, and AI finance assistant queries.
- Customer: Self-service portal: view active subscriptions and invoices, download GST-compliant PDFs, pay outstanding amounts via Razorpay, and manage WhatsApp communication.

8. API CONVENTIONS
----------------------------------------------------------------------
- Base path: /api/v1
- JSON request and response bodies only.
- Timestamps in ISO-8601 UTC format.
- Monetary amounts represented as strings formatted to 2 decimal places.
- Pagination: ?page=1&limit=20 (maximum 100).
- Standard envelope response: { "data": [...], "meta": { "page": 1, "limit": 20, "total": 500, "totalPages": 25 } }
- Error format: { "error": { "code": "VALIDATION_FAILED", "message": "...", "details": [...], "requestId": "..." } }
- Response headers: X-Request-Id, X-Response-Time.
- Default deny role guard on all routes; @Public() to opt out.

11. BUSINESS RULES (VERBATIM FROM SECTION 11)
----------------------------------------------------------------------
11.1 Subscription State Machine:
  DRAFT -> QUOTATION -> CONFIRMED -> ACTIVE -> CLOSED.
  PAUSED is handled via isPaused=true and pausedAt timestamp under ACTIVE status.
  Pausing stops billing; resume continues. Early close and renew check plan switches.

11.2 Billing Period Math:
  DAILY (+1d), WEEKLY (+7d), MONTHLY (+1 calendar month with clamp for end of month), YEARLY (+1y).
  periodStart = nextBillingDate before advance; periodEnd = periodStart + 1 period - 1 day.

11.3 Invoice Generation Algorithm:
  Row-lock subscription FOR UPDATE. Skip if not ACTIVE, paused, or nextBillingDate > asOf.
  Check unique (subscriptionId, periodStart, periodEnd).
  Build lines, apply valid discounts (usedCount < usageLimit conditional update), compute tax (2dp round), advance nextBillingDate.

11.4 Payments & Overpayment:
  Invoice row-lock. Reject if CANCELLED/DRAFT. min(amount, amountDue) applies to invoice.
  Excess amount increments Customer.creditBalance. If amountDue reaches 0, flip to PAID.

11.5 Razorpay Webhook:
  POST /api/v1/webhooks/razorpay. Verify X-Razorpay-Signature via HMAC-SHA256 with raw body.
  Store WebhookEvent(id) for replay idempotency. Record payment on payment.captured.

11.6 Payment Rescue:
  Classify failure reason. Auto-retry schedule via BullMQ delays. Manual simulation trigger.

11.7 Bank Reconciliation:
  Fuzzy score = 0.5*amount + 0.3*refContainsInvoice + 0.2*nameSimilarity. Net-of-fee (0.5% - 3%) tolerance.

11.8 WhatsApp Inbound & AI Assistant:
  Phone matched to verified Customer. Read-only views queried with timeout and row limit.

13. PERFORMANCE PLAN
----------------------------------------------------------------------
- P95 response time under 2000ms with 5,000+ subscriptions and 60,000+ invoices.
- Composite indexes on (status, nextBillingDate), (customerId, status), (issueDate).
- Keyset pagination with cursor on large listings.
- Redis caching (60s TTL) for aggregate summary statistics.
- Load-time badge visible in application footer.

20. GLOSSARY
----------------------------------------------------------------------
- MRR: Monthly Recurring Revenue.
- ARR: Annual Recurring Revenue (MRR * 12).
- Net-of-fee: Bank statement amounts where payment gateway processing fees were deducted prior to settlement.
- Proration: Proportional price calculation for mid-period plan upgrades or seat adjustments.
